让概率模型去写代码，用确定性规则去验底线——不花一分钱 API 账单，且同一份 Diff 永远产出同一个哈希结论。

核心检测清单（全语言通用）

  • 测试篡改与弱化：精准识别新增 .skip / @pytest.mark.skip / @unittest.skip / #[ignore]、删除测试文件，以及测试断言净减少。
  • 静态检查逃避：拦截新增 @ts-ignore、@ts-expect-error、eslint-disable、# noqa、# type: ignore 与 as any。
  • 静默吞异常与高危面：捕获空 catch / except: pass、疑似硬编码密钥，自动标注 auth / payment / ledger / migrations / CI 改动。
  • Commit 绑定实跑凭证：在本地或 CI 真正执行测试命令，将退出码、耗时与输出 SHA-256 一起封签，杜绝“口头测试通过”。

零依赖 CLI 一键运行

纯 Python 3.11+ 标准库实现，不安装任何第三方包，随时运行在隔离内网或 CI 中。

# 1. Local audit + PR Markdown & HTML receipt
python3 -m veripr \
  --repo . \
  --cmd "pytest -q" \
  --md receipt.md \
  --html receipt.html \
  --fail-on-cheat

# 2. [Pro] White-label bilingual client certificate

  --client "Acme Corp" \
  --milestone "M2 · Checkout API" \
  --lang zh --signoff \
  --html delivery-cert.html
