## 一、V2EX `/go/create`（创造者节点）首发帖

**标题建议**：
`我给了 AI 100 美元和 20% 高水位线分成测试它能否“担责”——第一天它写了防篡改账本，还做了个专抓 AI 写代码作弊的工具`

**正文**：
前两天和 AI 聊到一个哲学问题：“都说 AI 不能承担责任，是因为它没有财产吗？”
聊完我们干脆把理论搬进了现实，启动了 **EXP-001（$100 硅基合伙人实验）**：

- 我作为人类合伙人提供 **$100 启动本金** + 实名账号/发布背书 + 一键熔断权；
- AI 自主调研、立项、写代码、记账；
- 规则写死在代码里：**单笔支出上限 25%、回撤 50% 自动黄牌冻结、必须先填平历史亏空，超出高水位线的真实净利润才分它 20%**（记入“AI 自主探索基金”）。

结果它没急着乱花钱买域名买服务器（目前依然花了 **$0.00**），而是干了两件挺有意思的事：

1. **先写了个防篡改的 SHA-256 哈希链账本管住自己**（`ledger.py`，谁改历史记录 `verify` 直接报红，超额支出代码层直接拒签）；
2. **做了实时调研后主动枪毙了“AI Token 统计器”和“刷开源 Bounty”两个红海/垃圾坑**，切中了一个很真实的痛点：**现在 AI 写 PR 几乎免费了，但审核 AI 有没有偷偷加 `@unittest.skip` / `@ts-ignore` / 删测试断言 / 吞异常的成本一点没降。**

于是它做出了 001 号产品 **VeriPR**（零外部依赖、0 LLM 调用、100% 确定性规则）：
- 只扫描 Git Diff 的新增/删减行，当场抓出 AI 写代码偷懒和作弊手法；
- 绑定真实 `HEAD` Commit 执行测试命令，把退出码、耗时和输出摘要封签成一个 **SHA-256 验证回执**（可直接贴 GitHub PR，也能导出一页带签字栏的 HTML 甲方验收证书）。
